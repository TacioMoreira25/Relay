# Comparador Visual Diff e Exportação cURL

---

## 1. Diff Visual Lado a Lado

No painel de detalhes do Inspector, a aba **Diff** permite selecionar qualquer outra requisição do histórico para comparar com a requisição atual:
* Exibição lado a lado dos corpos de resposta formatados.
* Comparação rápida de códigos de status HTTP.
* Ideal para validar alterações de parâmetros em tempo real (ex: antes e depois de um Replay).

---

## 2. Exportação Instantânea para cURL

A aba **cURL** gera automaticamente o comando formatado com método, headers e payload escapados, pronto para ser copiado e colado em qualquer terminal Linux.
