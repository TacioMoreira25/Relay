# Otimizações para Linux & Atalhos de Teclado

O Relay foi otimizado para ambientes Linux (incluindo KDE Plasma e GNOME) e operações via teclado.

---

## 1. System Tray Nativo

- Ícone na bandeja do sistema com menu de contexto rápido:
  - "Mostrar / Ocultar Relay"
  - "Encerrar"
- Clique com o botão esquerdo na bandeja restaura o foco da janela principal.

---

## 2. Atalhos Globais de Teclado

| Atalho | Ação |
| :--- | :--- |
| `Ctrl + P` | Alterna o estado do Proxy HTTP (Iniciar / Parar) |
| `Ctrl + K` | Foca diretamente no campo de busca e filtros de tráfego |
| `Ctrl + L` | Limpa o histórico de requisições capturadas |
| `Ctrl + E` | Abre o modal de Exportação (HAR / OpenAPI) e Certificados HTTPS |
| `Ctrl + /` | Abre o Guia Rápido de Dicas e Atalhos |
