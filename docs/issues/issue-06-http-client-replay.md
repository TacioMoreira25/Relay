### 📋 Descrição
Capacidade de reenviar requisições gravadas com customização total de headers, query params e bodies.

### 🎯 Tarefas & Entregáveis
- [ ] Botão de "Replay" no painel de inspeção para duplicar uma chamada capturada.
- [ ] Editor interativo de headers via `HeaderEditor.svelte`.
- [ ] Auto-injeção do token JWT mais recente da sessão durante o disparo do replay.
- [ ] Histórico de disparos de replay com comparativo de respostas.
