### 📋 Descrição
Interceptação de tráfego seguro HTTPS via certificados CA locais e exportação de sessões.

### 🎯 Tarefas & Entregáveis
- [ ] Geração dinâmica de certificados raiz (CA) locais para interceptação de túneis TLS/HTTPS.
- [ ] Exportação de sessões gravadas para o formato padrão HTTP Archive (.har).
- [ ] Geração automática de especificações OpenAPI 3.0 baseadas no tráfego interceptado.
